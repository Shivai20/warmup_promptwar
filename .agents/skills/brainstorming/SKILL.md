# Brainstorming Skill

Use this skill before starting implementation to ensure full alignment with user requirements and brief constraints.

## Procedures

1. **Deconstruct Requirements:**
   - Review problem statement, target user personas, and hard constraints.
   - Separate official mandates from proposed assumptions.
   - Ensure the solution avoids isolated silos (e.g. single chatbot screens) and creates end-to-end connected workflows.

2. **Explore Product & UX Alternatives:**
   - Map user journeys step by step.
   - Identify failure modes (e.g. absent dates in notices, network disconnects, misheard speech).
   - Establish trust boundaries and non-goals.

3. **Validate Architecture & Scope Boundaries:**
   - Ensure implementation stays minimal and maintainable.
   - Preserve offline / manual fallback independence.
   - Formulate clear acceptance thresholds.
